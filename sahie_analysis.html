Uninsured Rates in Two Florida Counties (2008-2022)

Academic portfolio project

Project objective

Explore annual uninsured percentages in Miami-Dade and Bradford counties, assess stationarity, fit candidate ARIMA models, and generate five-year forecasts. This cleaned portfolio version is based on the author’s original R code and report; it is not a claim that all original numerical findings have been reproduced.

Data and preparation

The included CSV has 2008-2021 observations from the author’s cleaned Excel workbook and 2022 observations transcribed from the author’s updated report appendix. PCTUI is the uninsured percentage, not the number of uninsured people. PCTUI_MOE is the reported margin of error; this script does not use it as a modeling weight.

Stationarity and ARIMA modeling

Annual observations provide only 15 points per county. Models and ADF tests should therefore be interpreted cautiously. auto.arima is run with seasonal=FALSE because these are annual observations, not a seasonal series.

counties <- c("Miami-Dade County", "Bradford County")
series <- lapply(counties, function(nm) {
  d <- dat[dat$County == nm, ]
  d <- d[order(d$Year), ]
  stopifnot(identical(d$Year, 2008:2022))
  ts(d$PCTUI, start=2008, frequency=1)
})
names(series) <- counties
fits <- lapply(series, function(x) auto.arima(x, seasonal=FALSE, stepwise=FALSE, approximation=FALSE))
for (nm in counties) {
  cat("\n###", nm, "\n")
  print(adf.test(series[[nm]]))
  print(fits[[nm]])
  print(checkresiduals(fits[[nm]]))
}

Cross-correlation (exploratory)

The original project explored correlations at different lags. Raw trends can create misleading cross-correlations, and the sign of a CCF lag must be checked before claiming one county leads the other. The plot below is exploratory, not evidence of causation.

Interpretation

The source report describes a substantial decline in uninsured percentages over 2008-2022 in both counties, with different year-to-year patterns. Re-run the R Markdown document to obtain the selected models, diagnostics, and current forecast tables. Do not substitute the source report’s original model claims for the rerun output without verification.

Limitations

  • Only 15 annual observations per county; forecasts are uncertain.
  • 2022 data came from the report appendix, not an independently re-imported 2022 Census CSV.
  • The report’s 2022 standard-error column appears inconsistent with earlier years; those values were not carried into this dataset.
  • Annual observations do not justify seasonal ARIMA parameters.
  • County-level associations are not causal effects.
